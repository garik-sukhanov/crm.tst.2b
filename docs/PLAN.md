- [x] Tailwind v4 + shadcn/ui (radix), компоненты в `shared/ui`, `cn` в `shared/lib/utils`

### 3. База данных и безопасность (Supabase) — ✅ локально

- [x] схема: `profiles` (роль), `objects`, `tasks`, `task_status_transitions`, `task_status_history`, `task_comments`
- [x] RLS на всех таблицах + точечные GRANT по колонкам; по умолчанию запрещено всё
- [x] смена статуса только через `change_task_status` (переходы из таблицы), прямой UPDATE статуса запрещён
- [x] история пишется только базой; INSERT/UPDATE/DELETE через API запрещены
- [x] комментарии: читать и писать могут те, кто видит задачу; править и удалять нельзя
- [x] исполнитель не может менять задачи; исполнителем назначается только пользователь-исполнитель
- [x] открытая регистрация выключена (`config.toml`)
- [x] сид: 1 постановщик, 2 исполнителя, 3 объекта, 8 задач во всех статусах, история и комментарии
- [x] тесты: pgTAP (34 проверки в базе) + интеграционные через API (15), unit (23)
- [x] GitHub Actions: на каждый push — линтеры, типы, unit, сборка; Supabase в Docker — pgTAP и интеграционные
- [ ] накатить миграции и сид на облачный проект — нужен `supabase login` (ждёт пользователя)
