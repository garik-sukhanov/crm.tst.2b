# Решения и допущения

Что решили сами там, где ТЗ не даёт однозначного ответа. Пополняется по ходу работы; в конце из этого файла собирается пункт 4 сдачи.

## Стек

- **SPA на Vite, без серверной части.** Все правила доступа живут в базе (RLS и функции Postgres), поэтому отдельный сервер не нужен — фронтенд ходит в Supabase напрямую с публичным ключом.
- **Effector + Farfetched.** Бизнес-логика вынесена из компонентов в модели, что естественно ложится на слои FSD.
- **shadcn/ui + Tailwind.** Компоненты лежат в коде проекта, их можно править под себя; темы через CSS-переменные.
